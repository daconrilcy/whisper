## Reproductibilité

Le toolkit et les sorties de build résident sous `WhisperBuildDeps` et `%TEMP%`; ils ne sont pas incorporés au dépôt. Pour le build package, initialiser d'abord l'environnement avec `C:\Program Files (x86)\Microsoft Visual Studio\2019\BuildTools\Common7\Tools\VsDevCmd.bat -arch=x64 -host_arch=x64`, puis définir les variables locales listées ci-dessus, avec `CMAKE_CUDA_ARCHITECTURES=61`, avant la commande Cargo.
