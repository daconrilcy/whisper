# Railguard du futur produit — proposition, non active

**Portée proposée :** tout futur code Rust, build, installateur et données de migration du produit Whisper Windows V1. Ce document n'est pas un `RAILGUARD.md` actif. Autorité d'activation : utilisateur ou autorité de gouvernance désignée dans un futur `AGENTS.md`, par acte traçable donnant chemin cible, hash de cette proposition revue, hash actif, date et contrôle d'effet normatif équivalent. Ne pas copier implicitement ce fichier dans la racine du dépôt.

## Préflight de chaque lot futur

Vérifier source et autorité du design READY, exactitude manifest/digest/revue CLEAN, décisions Q nécessaires, preuve des SPIKE applicables, état de l'activation du railguard et SHA actif, branche/checkout, dépendances et migration. Un lot dépendant d'un détail Q encore ouvert attend ce détail ; les autres peuvent être planifiés après gate DESIGN. Une divergence du code source initial ou des preuves d'exécution suspend seulement les lots touchés jusqu'à analyse CHANGE.

## État

Proposition soumise à revue indépendante dans D-WHISPER-03. **Non active** et non transférable au code tant que le design n'est pas READY et qu'une activation équivalente n'a pas été attestée pour les lots qui l'exigent.
