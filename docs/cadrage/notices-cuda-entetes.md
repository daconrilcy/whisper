# Notices des en-têtes CUDA du worker GPU

Avancée : notices extraites des en-têtes relevés par les dépendances Ninja du build GPU.
Blocage : la trace ne prouve pas quels éléments sont incorporés après liaison ni la couverture des en-têtes système masqués.
Décision : conserver ces notices dans l'ensemble prudent à examiner pour la remise L3.

Le `compile_commands.json` du worker GPU contient 150 unités ; `ninja -t deps` fournit 150 enregistrements valides et 1 399 en-têtes distincts, dont 874 sous `CUDA/v12.9/include`. Les 874 fichiers ont été lus. Parmi eux, 823 contiennent dans leurs 120 premières lignes au moins un bloc de commentaire reconnu comme notice de copyright ou licence ; les autres peuvent avoir une licence ailleurs ou être couverts par le toolkit. Les 126 blocs distincts sont reproduits ci-dessous, avec les chemins relatifs à `CUDA/v12.9/include` des en-têtes où ils ont été observés.

La détection se limite aux blocs et motifs reconnus : elle ne démontre pas l'absence d'autres notices. Les chemins Ninja sont des dépendances enregistrées, pas une preuve de code présent après liaison. Le texte complet Apache-2.0, l'exception LLVM et Boost 1.0 sont disponibles dans le [recueil](recueil-licences-candidates-turbo.md). Les notices BSD de CUB sont reproduites dans les blocs concernés. Le fichier `NOTICE` cité par certains en-têtes Thrust n'a pas été trouvé dans le toolkit local ; le texte Boost 1.0 correspondant est inclus dans le recueil.

Une recherche complémentaire sur l'intégralité des 51 fichiers sans bloc reconnu dans les 120 premières lignes n'a trouvé aucun des mêmes marqueurs de copyright ou licence. Cela ne signifie pas qu'ils sont sans licence : beaucoup sont des en-têtes générés `cuda/__ptx`, et les conditions des composants doivent aussi être déterminées depuis le toolkit et le projet amont. Le macro local `CCCL_VERSION` vaut `2008002` ; la [licence CCCL 2.8.2](https://github.com/NVIDIA/cccl/blob/v2.8.2/LICENSE) indique notamment Apache-2.0 avec exception LLVM pour libcu++, Apache-2.0 avec exceptions pour Thrust et BSD 3 clauses pour CUB. La correspondance octet à octet de l'ensemble du toolkit avec ce tag n'est pas établie.
